## Agent skills

### Issue tracker

Issues 跟踪在本 repo 的 GitHub Issues，所有操作使用 `gh` CLI。See `docs/agents/issue-tracker.md`.

### Triage labels

使用五个默认 canonical triage labels（`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`）。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：repo root 的 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.

# v1 采用单机 Docker Compose 部署，可用性目标分阶段达标

v1 的生产环境是一台 2核2G/3M 云虚拟机，仅承担"完成发布"的演示职能，不承载真实业务流量；开发与压测在 8G 内存的 WSL 虚拟机完成；开发者计划 v2 学习 K8s 后重新部署。我们决定：v1 用 Docker Compose/systemd 直跑全部服务与中间件（单副本、小堆内存）；生产可用性降为 best-effort（容器自愈 + 人工恢复），RPO ≤5 分钟（每日备份 + binlog）；99.95% 与 RPO<1min 转为 v2（K8s 多节点）目标，v1 期间在压测环境验证吞吐、时延与消息可靠性等机制。"全国档"作为设计量级与压测验收口径，不作为 v1 生产流量预期。
